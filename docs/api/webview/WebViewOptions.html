StageWebView

typedef WebViewOptions

package webview

What a webview.WebView is created with. Everything is optional.

Example

var webView = new webview.WebView(windowHandle, {
	devTools: true,
	userAgent: "StageWebView demo"
});

Fields

@:optionaloptionalzoom:Null<Bool>

Whether the user can zoom the page. true by default.

@:optionaloptionaluserAgent:Null<String>

What the webview says it is, in place of the engine's own user agent.

@:optionaloptionalstatusBar:Null<Bool>

Whether the status bar shows, as it does over a link. true by default.

@:optionaloptionalkeyboardShortcuts:Null<Bool>

Whether browser shortcuts, such as the one to print, work. true by default.

@:optionaloptionalhidden:Null<Bool>

Whether the webview has no visible window, for off-screen work such as printToPDF(). false by default, and only for a webview without a host window.

Windows parents WebView2 into a window that is never shown, Linux uses a GTK offscreen window, macOS an off-screen window, and iOS and Android a view that is never attached to the screen.

@:optionaloptionaldevTools:Null<Bool>

Whether the engine's developer tools are available. false by default.

@:optionaloptionalcontextMenu:Null<Bool>

Whether the user can open the page's context menu. true by default.

@:optionaloptionalautoplay:Null<Bool>

Whether media plays without waiting for a user action. false by default. Applied on Linux, macOS, iOS and Android.
